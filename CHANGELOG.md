# Changelog

All notable changes to the **Crowdify** project will be documented in this file.

## [1.1.0] - 2026-02-15
### Added
- Vanta.js interactive 3D background.
- HSL-based glassmorphism design system.
- ISO-8601 timestamping to intelligence data.
- Serverless Vercel deployment support.

### Changed
- Refactored intelligence logic into `monitor.py`.
- Optimized person detection confidence thresholds.

### Fixed
- Fixed model path resolution for cloud environments.
- Improved dashboard responsiveness for wide screens.

## [1.0.0] - 2026-02-13
- Initial release with real-time crowd monitoring and heatmap generation.
