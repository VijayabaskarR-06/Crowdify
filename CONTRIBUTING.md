# Contributing to Crowdify

Thank you for your interest in improving **Crowdify**!

## Getting Started

1. **Fork the Repository**: Create your own copy of the project.
2. **Clone Locally**: 
   ```bash
   git clone https://github.com/VijayabaskarR-06/Crowdify.git
   ```
3. **Environment Setup**:
   ```bash
   pip install -r requirements.txt
   pip install -r requirements-dev.txt
   ```

## Development Workflow

- **Style Guide**: We follow PEP 8 for Python and use `black` for formatting.
- **Testing**: Run tests using `pytest`.
- **Commits**: Use semantic commit messages (e.g., `feat:`, `fix:`, `style:`, `refactor:`).

## Pull Requests

1. Create a new branch for your feature or fix.
2. Ensure all tests pass.
3. Submit a PR with a clear description of changes.
